# tools/

`qa-tools`, the CI tooling: `java -jar tools/target/qa-tools.jar <command>` with `triage`, `heal`,
`report`, `merge`, `quarantine-check` and `flaky-history`. The same commands, categories and JSON
formats exist in TypeScript in the UI flagship. See [self-healing](../docs/self-healing.md) and
[reporting](../docs/reporting.md).
